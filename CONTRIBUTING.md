# Contributing

Thank you for your interest in BoogieBox.

BoogieBox is currently accepting:

- Bug reports
- Feature suggestions
- General feedback

Please submit these through [GitHub Issues](https://github.com/yossironnen/BoogieBox/issues).

## Code Contributions

Code contributions and pull requests are not being accepted at this time.

You are welcome to fork the repository for personal experimentation, but please do not open pull requests until the contribution policy changes.

When reporting a bug, include the BoogieBox version, relevant steps to reproduce the problem, and any useful error messages. Do not include passwords, API keys, private file paths, or other sensitive information.
