# Project Skills

Repo-specific Codex skills live here so they can ship with the project.

## Layout

Each skill should use its own folder:

```text
.codex/
  skills/
    my-skill/
      SKILL.md
      scripts/
      templates/
      assets/
      references/
```

## Notes

- `SKILL.md` is the required entrypoint.
- Keep paths inside a skill relative to that skill folder.
- Commit project skills with the repo when the team should share them.
- Use one folder per skill to keep prompts, scripts, and references together.
