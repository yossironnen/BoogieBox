# Example Project Skill

Use this skill when work needs project-specific context or a repeatable repo workflow.

## Purpose

This folder is a starter template for BoogieBox project skills.

Copy this folder, rename it, and replace the instructions below with the real workflow.

## Recommended Structure

- `SKILL.md`: skill instructions and trigger guidance
- `scripts/`: helper scripts the skill can call
- `templates/`: reusable file templates
- `assets/`: static assets used by the skill
- `references/`: focused docs or examples

## Example Workflow

1. Read only the repo files needed for the task.
2. Prefer existing scripts and templates over rewriting large blocks manually.
3. Keep edits small and aligned with project conventions.
4. Update project memory and `changes.log` when the task changes repo state.

## Replace Me

Rename this folder to a real skill name before relying on it for production work.
